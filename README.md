# Коды полей Bitrix24

Расширение добавляет маленькую кнопку рядом с названием поля в открытой карточке CRM или смарт-процесса. Наведение показывает значение `data-field-tag`, нажатие копирует его. Общий переключатель находится в меню расширения.

## Установка в Chrome

1. Скопируйте эту папку на компьютер сотрудника.
2. Откройте `chrome://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Обновите уже открытые вкладки Bitrix24.

Для обновления замените файлы и нажмите «Обновить» на странице расширений. Расширение запрашивает доступ к HTTP/HTTPS-сайтам, чтобы работать на порталах с любым доменом. Оно не использует сеть и не отправляет данные.
